# Compatibility

## RootHide 0.8.0

The public 0.8.0 package is intended for supported Dopamine 2 RootHide environments using the RootHide Bootstrap. The same package supports the applicable arm64 and arm64e RootHide targets.

RootHide Patcher is required before installation. Install the patched package through Sileo and perform a Userspace Reboot when requested.

## Not supported

- conventional, non-RootHide Dopamine installations;
- rootful jailbreak environments;
- packages installed without RootHide Patcher;
- modified package identity or arbitrary profile values outside the provided settings.

Compatibility is environment-specific. If the settings panel does not appear or the tweak reports an unhealthy state, use the [troubleshooting guide](docs/editions/roothide/TROUBLESHOOTING.md) before filing a report.

The Dopamine edition is frozen as a private Alpha and is not publicly packaged.

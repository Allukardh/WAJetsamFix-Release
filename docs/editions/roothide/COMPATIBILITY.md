# RootHide compatibility

WAJetsamFix 0.8.0 is intended for supported Dopamine 2 RootHide environments using the RootHide Bootstrap. The package supports the applicable arm64 and arm64e RootHide targets.

RootHide Patcher is mandatory before installation. Install the patched package through Sileo and use Userspace Reboot when requested.

Conventional Dopamine, rootful environments, unpatched packages, modified package identities and arbitrary profile values are outside the supported configuration.

For installation problems, see [troubleshooting](TROUBLESHOOTING.md).

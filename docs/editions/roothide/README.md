# WAJetsamFix 0.8.0 for RootHide

RootHide 0.8.0 is the stable public edition of WAJetsamFix.

## Features

- Manual 48 MB, 72 MB and 96 MB profiles.
- A bounded calibration assistant that recommends one of the supported profiles.
- Explicit profile application; calibration never changes the active profile automatically.
- PreferenceLoader settings panel with the final WAJetsamFix icon.
- RootHide Userspace Reboot integration after configuration changes.
- Status information for confirming the installed version and current configuration.

## Safety boundaries

WAJetsamFix targets only its intended WhatsApp configuration. It does not enable a global Jetsam override, continuously poll processes, automatically repair files or accept arbitrary profile values.

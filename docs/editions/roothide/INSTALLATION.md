# Installing RootHide 0.8.0

1. Download `com.allukardh.wajetsamfix_0.8.0_iphoneos-arm64.deb` from the [v0.8.0 release](https://github.com/Allukardh/WAJetsamFix-Release/releases/tag/v0.8.0).
2. Verify its SHA-256 against [CHECKSUMS.txt](../../../CHECKSUMS.txt).
3. Process the package with RootHide Patcher.
4. Open the patched package in Sileo and install it.
5. Perform a Userspace Reboot when requested.
6. Open Settings and confirm that the WAJetsamFix panel and icon are present.

Do not install the unpatched package into a RootHide environment.

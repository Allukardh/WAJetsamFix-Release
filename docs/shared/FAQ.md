# FAQ

## Which edition is public?

RootHide 0.8.0 is the stable public edition. The Dopamine edition remains a frozen private Alpha and has no public package.

## Which profiles are available?

48 MB, 72 MB and 96 MB. Only these predefined profiles are supported.

## Does calibration change the profile automatically?

No. It recommends a supported profile; application remains manual and explicit.

## Does WAJetsamFix change Jetsam globally?

No. Its scope is limited to the intended WhatsApp configuration.

## Why is RootHide Patcher required?

The public package must be adapted for the RootHide environment before installation. Patch it first, then install the resulting package through Sileo.

## Where is the official package?

Only on the [v0.8.0 GitHub Release](https://github.com/Allukardh/WAJetsamFix-Release/releases/tag/v0.8.0). Verify its SHA-256 before installing.

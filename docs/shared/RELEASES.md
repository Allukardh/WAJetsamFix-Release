# Release policy

## Stable package

RootHide 0.8.0 is a regular, Latest release with exactly one asset: the final RootHide `.deb`.

## Historical 0.8 prereleases

The Alpha 1, Alpha 1.1, Alpha 1.2, Alpha 1.3, Alpha 2 and Alpha 2.1 releases are preserved as prerelease notes only. They contain no downloadable assets.

No 0.8 release candidate was created.

## Distribution boundary

This public repository distributes approved release documentation and final public packages only. Source code, private validation material and internal build records are not published here.

The Dopamine edition remains frozen as a private Alpha and has no public package.

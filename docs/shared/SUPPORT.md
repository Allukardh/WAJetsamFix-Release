# Support policy

Public support applies to the RootHide 0.8.0 package distributed by this repository.

Before reporting a problem, verify the package checksum, confirm that RootHide Patcher was used, perform a Userspace Reboot and follow the RootHide troubleshooting guide.

Include only the information needed to reproduce the problem: installed package version, selected profile, visible status and steps. Do not publish private data, tokens or unrelated logs.

The frozen private Dopamine Alpha is not a public support target.

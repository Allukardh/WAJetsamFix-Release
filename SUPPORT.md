# Support

Before requesting support:

1. Confirm that you installed the RootHide 0.8.0 package from this repository.
2. Verify its SHA-256 against [CHECKSUMS.txt](CHECKSUMS.txt).
3. Confirm that RootHide Patcher was used before installation.
4. Perform a Userspace Reboot.
5. Review the [usage](docs/editions/roothide/USAGE.md) and [troubleshooting](docs/editions/roothide/TROUBLESHOOTING.md) guides.

When reporting a problem, include the installed package version, the selected profile, the visible status output and the exact steps that reproduce the issue. Do not post private data, authentication material or unrelated system logs.

Support covers the public RootHide package. The frozen private Dopamine Alpha is not a public support target.

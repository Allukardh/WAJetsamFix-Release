# Changelog

## RootHide 0.8.0 — stable

- Promotes the RootHide edition to the final 0.8.0 identity.
- Provides manual 48 MB, 72 MB and 96 MB profiles.
- Includes a bounded calibration assistant that recommends one of the supported profiles.
- Keeps profile application manual and explicit.
- Adds the finalized PreferenceLoader panel, descriptions and icon.
- Uses Userspace Reboot for the RootHide environment after configuration changes.
- Preserves the scoped safety model: no global Jetsam override, background polling, automatic repair or silent profile application.

## RootHide 0.8 prerelease history

- **0.8.0 Alpha 1:** introduced the 0.8 RootHide settings foundation and manual profiles.
- **0.8.0 Alpha 1.1:** corrected PreferenceLoader registration and restart signaling.
- **0.8.0 Alpha 1.2:** corrected the settings container and panel presentation.
- **0.8.0 Alpha 1.3:** aligned restart behavior with RootHide Userspace Reboot.
- **0.8.0 Alpha 2:** introduced bounded calibration and finalized the manual recommendation flow.
- **0.8.0 Alpha 2.1:** refined button state and user-facing descriptions without changing the runtime behavior.

No release candidate was required or published for 0.8.0.
